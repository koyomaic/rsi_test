# 玻璃研究数据源排查报告（F1 阶段）

- **审计日期**：2026-11-19（当日数据全部为本任务实时抓取实测）
- **任务性质**：框架数据矩阵可行性验证——只测数据可得性，不做研判、不改台账
- **方法**：websearch + webfetch 实测。websearch 本会话持续返回空结果（多个中文关键词均无结果），故全部改为 webfetch 直连候选源实测；以下所有数值与 URL 均为当次抓取记录
- **工具能力边界说明**：webfetch 无 JS 执行能力、无法自定义 UA。郑商所官网 412（WAF 反爬）与东财动态加载页面对本环境不可用，属工具边界，不代表源本身无效

## 一、沙河玻璃现货价

### 1.1 生意社玻璃频道 —— 推荐主源（日度）

- **源名称**：生意社（大宗商品数据平台）玻璃频道
- **URL**：https://glass.100ppi.com/ ；日度基准价新闻示例：https://www.100ppi.com/news/detail-20261119-6512929.html
- **实测结果**：✅ 成功。2026-11-19 08:30 发布「11月19日生意社玻璃基准价为12.25元/平方米」。连续抓到日度序列：

  - 另有价格快讯（16:38 更新）与每日趋势分析文（如 11-19「弱势反弹」，含均差指标 D5/D10/D20 与多空信号）
  - **附带发现**：该频道同时镜像郑商所玻璃期货全合约日行情（11-18 实测：FG2701 收盘 899 / 结算 900 / 持仓 1134297，全 12 个合约均有 OHLC/量仓）——可作期货数据免费兜底
- **更新频率**：日度（基准价新闻每个交易日 08:30；快讯 16:38）
- **局限**：口径为全国基准价（元/平方米），**非「沙河 5mm 级白玻」专项报价**；沙河 5mm 专项报价属卓创/隆众付费数据，免费层未找到
- **可靠性评级**：**稳定**

### 1.2 金投网玻璃频道 —— 推荐辅源（沙河专项价，周度）

- **源名称**：金投网期货频道（转载期货公司日报）
- **URL**：https://futures.cngold.org/boli/ ；实测样例文：https://futures.cngold.org/boli/c10854845.html
- **实测结果**：✅ 成功。广发期货日报（2026-11-03 09:50）披露「**沙河地区大板出厂价 850-910 元/吨**，湖北本地实际成交 900-970 元/吨」（元/吨口径，与 FG 期货同单位）。频道资讯列表显示玻璃文章持续更新（11-03 / 11-10 / 11-13 / 11-16 / 11-18 均有玻璃供需类文章），另有每个交易日 09:04 左右发布的「今日最新玻璃期货价格查询」（11-19 实测：主力开盘 901 / 昨收 899）
- **更新频率**：沙河元/吨报价随期货公司日报出现，约周度；期货价格查询文日度
- **可靠性评级**：**稳定**

### 1.3 中玻网 —— 不可用

- **URL**：http://www.glass.com.cn/
- **实测结果**：❌ 抓取返回 GBK 编码乱码（页面为 B2B 供应商报价目录，如 supply/fufaboli119_1.html 浮法玻璃报价列表），无结构化行情数据，机器解析不可用
- **可靠性评级**：**不可用**

### 1.4 百川盈孚 / 隆众 / 卓创公开层 —— 不可用（付费墙）

- 隆众 oilchem.net 实测：首页与建筑材料频道（building.oilchem.net）可抓，但建材频道以水泥/砂石/混凝土为主**无玻璃子频道**；玻璃数据在其价格中心/数据终端（dc.oilchem.net、dt.oilchem.net）登录付费墙内；公开层仅见「纯碱玻璃产业调研（湖北站）」走访日记类文章（2026-11-05/11-06）
- **可靠性评级**：公开免费层**不可用**

### 结论（任务1）

**可用**。推荐组合：日度用**生意社玻璃基准价**（12.25 元/㎡，趋势代理）+ 约周度用**金投网期货日报的沙河出厂价**（850-910 元/吨，与期货同口径）。免费层拿不到日度「沙河 5mm」专项价。

## 二、郑商所会员持仓排名（FG 前 20 会员多空持仓）

### 2.1 郑商所官网 —— 直连不可用

- **URL**：http://www.czce.com.cn/ 及深层路径（/cn/gyjys/jystj/mrjystj/index.html）

- **更新频率**：**日度**（首页「国内持仓」表亦显示玻璃持仓总量 2062402、成交总量 2059312、日期 2026-11-19，当日更新）
- **口径备注**：默认「全部合约」加总口径；页面有合约/日期选择器（另有 /data/positionContract 会员持仓合约、/data/positionHistory 持仓历史子页）。第三方镜像，与郑商所原始数据一致性需抽样核对
- **可靠性评级**：**稳定**

### 2.3 东方财富期货龙虎榜 —— 页面在、数据抓不到

- **URL**：http://data.eastmoney.com/futures/sh/data.html
- **实测结果**：⚠️ 页面确认存在（「商品期货持仓数据一览/合约会员成交持仓龙虎榜」，支持交易所=郑商所、品种、合约、日期、成交/多单/空单/净多/净空/增减仓各榜单），但**表格数据由 JS 动态加载**，webfetch 抓到的 HTML 只有表头框架、无数据行（数据来源标注东方财富 Choice）

## 三、厂家库存兜底源（新闻披露渠道）

### 3.1 生意社 PriceSeek 新闻 —— 实例 1

- **URL**：https://www.100ppi.com/news/detail-20261030-6422789.html
- **实测结果**：✅ 「PriceSeek提醒：浮法玻璃库存下降相关商品行情分析」（2026-10-30 17:16）原文：
  > 「截止10月30日，全国浮法玻璃样本企业总库存 **7051.9 万重箱**，环比减少 **50.9 万重箱**，降幅达 0.72%，同比增幅为 7.19%。折**库存天数 32.2 天**，较上期减少 0.2 天。」
  - 数字质量高：绝对量 + 环比 + 同比 + 折天数四要素齐全（原口径来源应为隆众/卓创周度样本企业统计）
- **更新频率**：不定期（玻璃频道列表中库存类最近一篇为 10-30，约周度或事件驱动）
- **可靠性评级**：**稳定**

### 3.2 金投网转载期货公司日报 —— 实例 2（双源交叉验证）

- **URL**：https://futures.cngold.org/boli/c10854845.html
- **实测结果**：✅ 广发期货日报（2026-11-03 09:50）：
  > 「截止到 20261029，全国浮法玻璃样本企业总库存 **7051.9 万重箱**，环比 **-50.9 万重箱**，环比 -0.72%，同比 +7.19%。折库存天数 **32.2 天**，较上期 -0.2 天。」
  - **交叉验证通过**：与生意社 3.1 的数字**完全一致**（7051.9 / -50.9 / 32.2 / -0.2），两渠道同源互相印证，可信度增强
- **更新频率**：约周度（随期货公司日报）
- **可靠性评级**：**稳定**

### 结论（任务3）

**可用**。新闻渠道**定期（约周度）给出具体数字**，且生意社与金投网两渠道数字交叉一致（7051.9 万重箱 / 32.2 天）。厂家库存天数作为兜底指标可行。

## 六、总体结论与建议

1. **四项数据全部可行**，免费公开渠道即可搭建数据矩阵雏形，无需付费数据源即可起步
2. **最稳固的一项**：持仓排名（99qh 静态表格 + 当日更新 + URL 参数化），建议直接纳入研究员取数流程替代郑商所官网
3. **最需注意的一项**：沙河现货价——免费层只有「日度全国基准价（元/㎡）」与「周度沙河出厂价（元/吨）」两级粒度，日度沙河 5mm 专项价是付费数据（卓创/隆众），框架若要求日度沙河专项价需购买数据或降级口径
4. **库存与日熔量**为约周度频率（非日度），做日线级研判时应作为低频验证项而非每日驱动项
5. 风险提示：99qh 为第三方镜像（与交易所原始数据一致性需抽样核对）；金投网/生意社的玻璃供需数据同源于隆众/卓创样本口径（两渠道数字完全一致），单一样本口径的系统性偏差无法通过多源交叉消除
6. 本环境 websearch 本次不可用（持续空结果），后续取数任务宜直接使用本报告已验证的 URL 清单
