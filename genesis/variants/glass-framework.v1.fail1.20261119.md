# 玻璃（FG）价格研判框架 v1.0（草案）

> 状态：draft，待 genesis-evaluator 裁决；未经 PASS 不得作为 glass-researcher 的正式研判依据。
> 框架目标：为 FG 主力合约的下一交易日研判提供可追溯的方向、区间与执行依据，最终服务于 G2 胜率、G3 入场率、G4 零违规，以及计划上线的 G5 方向准确率、G6 区间覆盖率。
> 方法来源：`glass/research/methodology-survey.md`；数据可得性依据：`glass/research/data-source-audit.md`（均为 2026-11-19 实测）。
> 本文件是方法契约，不是当日研报，不给出当前交易建议。初始权重与阈值均为待验证的启发式先验，不是已经证明有效的参数。

---

## 一、适用范围与边界

### 1.1 解决什么

1. 用周度/月度产业数据形成中期方向先验；
2. 用日度期现与持仓数据确认或否定短线方向；
3. 将方向先验交给现有技术区间层与执行层，不取代 ATR、支撑压力和结算纪律；
4. 让每个判断均可追溯到原始数据、日期、口径和计算过程。

### 1.2 不做什么

1. 不预测政策发布时间与突发事件；
2. 不用成本线直接猜绝对底部，不把“亏损”自动等同于“马上上涨”；
3. 不把会员席位持仓当成机构自营方向，不用单日净持仓独立决定交易；
4. 不把全国元/㎡报价与 FG 元/吨价格直接相减；
5. 不用周度库存或日熔量伪装成日度新信号；
6. 不用 MCP 中不存在或已停更的 FG/SA 指标凑数据；
7. 不修改结算规则、不执行交易、不给出扛单或摊平建议。

## 二、三层决策结构

```text
第一层：方向先验
  库存（30%）+ 供给（25%）+ 需求（25%）+ 基差/月差（20%）
  → 加权评分 S ∈ [-2, +2] → 偏多 / 偏空 / 中性 + 数据覆盖率 + 置信度

独立修正器（不直接加权）
  成本利润：判断产业下沿与供给收缩是否兑现，不单独触发反转
  会员持仓：确认/背离，只调整置信度和风险提示
  事件：单列传导链与有效期，不用标题直接改方向

第二层：技术区间
  沿用现有 ATR5、近 5 日高低点、整数关口与 S1/S2/R1/R2

第三层：入场执行
  沿用现有触发/止损/目标、入场可达性自检、每日最多一笔与不扛单红线
```

**设计理由**：五派方法不是同质因子。库存、供需和期现结构可以形成方向证据；成本是慢变量与下沿约束；资金是确认器。强行全部加权会制造虚假精确和重复计数。

## 三、统一数据契约

每个进入框架的数据必须记录以下字段，缺一不可：

```yaml
factor: inventory | supply | demand | basis | cost | positioning | event
value: 原始数值或区间
unit: 原始单位
region: 全国 / 沙河 / 湖北 / 其他
spec: 品规、含税口径、样本口径或合约范围
as_of: 数据所属日期（不是网页发布日期）
published_at: 页面发布时间（能取得时）
retrieved_at: 当次获取时间
source_url: 可复核 URL；MCP 则写工具与参数
freshness: fresh | stale
```

### 3.1 新鲜度规则（初始）

| 数据 | 默认频率 | fresh 条件 | 超过期限 |
|---|---|---|---|
| FG 行情、持仓、月差 | 日度 | 基日 D 或此前最近一个交易日 | stale |
| 全国现货趋势代理 | 日度 | 最近一个交易日 | stale |
| 沙河现货、库存、日熔量、生产利润、深加工订单 | 约周度 | as_of 距 D 不超过 14 个自然日 | stale |
| 地产竣工等月度数据 | 月度 | as_of 距 D 不超过 45 个自然日 | stale |
| 冷修/点火/政策事件 | 事件驱动 | 必须单独判断影响是否仍持续 | 不自动沿用 |

- `stale` 数据可写入背景，但退出方向评分；不得把缺失或 stale 记成中性 0 分。
- 同一周度数据在连续交易日沿用，必须保留原 `as_of`，不得改写成当日数据。
- 两个转载页面若同源于卓创/隆众，只能证明转载一致，不能算两个独立产业样本。

### 3.2 数据源矩阵（F1 实测版）

| 用途 | 主源 | 辅源/兜底 | 使用限制 |
|---|---|---|---|
| FG 日 K 与全合约行情 | 新浪等现有行情接口 | https://glass.100ppi.com/ | 结算仍按现有数据诚信规则 |
| 日度现货趋势 | https://glass.100ppi.com/ | — | 全国基准价元/㎡，只看趋势，不算 FG 绝对基差 |
| 沙河现货与绝对基差 | https://futures.cngold.org/boli/ 期货日报转引 | 其他明确品规的公开研报 | 约周度；必须元/吨、同区域品规 |
| 前 20 会员多空持仓 | https://www.99qh.com/data/positionRanking?productId=50&contract=玻璃 | 郑商所/东财（当前工具受限） | 默认全部合约口径，须标注；抽样核对交易所原始值 |
| 库存与库存天数 | 生意社 PriceSeek + 金投网期货日报 | 新浪研报转引 | 固定同一样本口径看环比/同比 |
| 日熔量与周产量 | 金投网期货日报 | 其他期货公司周报 | 周度方向过滤，不作日内触发 |
| 冷修/复产事件 | 生意社 PriceSeek 产线新闻 | 玻璃工业网/周报 | 记录单线产能与事件日期 |
| 需求 | 国家统计局月度数据 + 周报深加工订单 | 公开研报 | 单期同比只描述水平，方向评分优先看连续变化 |
| 成本利润 | SA 日行情 + 周度三路线利润 | 公开产业拆算 | 燃料路线分开；估算必须标“估算” |
| 能源与宏观背景 | crude-data MCP | 公开 web | MCP 实测不覆盖现用 FG/SA 指标，不作玻璃主数据 |

## 四、方向因子与评分规则

### 4.1 通用规则

- 单因子评分 `s_i ∈ {-2,-1,0,+1,+2}`：正=偏多，负=偏空，0=已取得的证据确实中性或相互抵消。
- 数据缺失或 stale：`s_i = null`，不是 0。
- 每个评分必须写出“原始观察 → 评分”的一句理由；不得只给分数。
- 若达不到某档全部条件，就降档；不得为了方向鲜明而升格。

### 4.2 库存因子（权重 30%）

观察：同口径样本企业总库存、库存天数、环比、同比；可得时附厂库/社库结构。

| 分数 | 初始判据 |
|---|---|
| +2 | 连续 3 周去库，且同比增幅收窄至 10%以内，库存天数同步下降 |
| +1 | 连续 2 周去库且库存天数下降，但同比仍高或改善未达 +2 |
| 0 | 单周变化、总量与天数背离，或去库/累库交替无趋势 |
| -1 | 连续 2 周累库且库存天数上升 |
| -2 | 连续至少 3 周累库，且同比增幅≥10%或继续扩大 |

结构约束：厂库向社库转移单列“库存转移”，不能直接当作终端消费改善；只有订单、现货或持续去库共同验证时才可升档。

### 4.3 供给因子（权重 25%）

观察：全国浮法日熔量、周产量、冷修/复产净变化。

| 分数 | 初始判据 |
|---|---|
| +2 | 日熔量连续两周低于 13.5 万吨/日，且有可核实的净冷修收缩 |
| +1 | 日熔量连续两周下降，或已核实的冷修产能大于点火/复产产能 |
| 0 | 日熔量稳定，或冷修与复产产能相等/无法判断净方向 |
| -1 | 日熔量连续两周上升，或点火/复产产能大于冷修 |
| -2 | 日熔量连续两周上升且新增点火/复产形成明确净扩张 |

13.5 万吨/日只是本轮调研得到的初始紧平衡参照，不是永久自然常数；月度框架评审时必须复核其适用性。开工率下降但日熔量上升时，以有效供给日熔量为准。

### 4.4 需求因子（权重 25%）

观察：深加工订单天数、Low-e 开工率、地产竣工及新开工；光伏等需求单列，不与浮法地产需求混算。

| 分数 | 初始判据 |
|---|---|
| +2 | 订单与地产需求指标均连续两期改善 |
| +1 | 订单连续两周改善，或竣工同比降幅连续两个月收窄 |
| 0 | 指标稳定、相互矛盾，或只有单期水平无法判断趋势 |
| -1 | 订单连续两周走弱，或竣工同比降幅连续两个月扩大 |
| -2 | 订单与地产需求指标均连续两期恶化 |

单期“同比 -25%”只能说明需求弱，不能单独证明需求仍在边际恶化；评分必须区分水平与趋势。

### 4.5 基差/月差因子（权重 20%）

计算：

```text
绝对基差 = 同区域、同品规、同税口径现货（元/吨）− 对应 FG 合约结算价（元/吨）
月差 = 近月合约结算价 − 远月合约结算价（同一交易日）
```

现货为区间时，基差也保留区间，不得擅自取中点制造精确值。

观察三项：现货价格趋势、绝对基差变化、近远月月差变化。

| 分数 | 初始判据 |
|---|---|
| +2 | 现货走强、基差走强、近月月差走强三项共振 |
| +1 | 三项中两项走强，另一项不反对 |
| 0 | 三项相互抵消或均无明显变化 |
| -1 | 三项中两项走弱，另一项不支持多头 |
| -2 | 现货走弱、基差走弱、近月月差走弱三项共振 |

特别警示：期货上涨但现货不跟、基差走弱，属于“预期虚涨”风险，不能因为盘面上涨给该项加分。

口径降级：若只有全国元/㎡日度趋势、没有同单位沙河现货，则该因子最多给 `+1/-1`，且不得输出绝对基差数值；若连可比趋势也没有，则为 null。

## 五、方向合成、覆盖率与置信度

### 5.1 加权评分

设可用因子集合为 A，权重分别为库存 0.30、供给 0.25、需求 0.25、基差/月差 0.20：

```text
覆盖率 C = Σ(i∈A) w_i
方向分 S = Σ(i∈A) w_i × s_i / C       （仅当 C > 0）
```

S 的理论范围为 [-2,+2]。缺失因子不参与分子与分母，禁止按 0 分补齐。

### 5.2 方向判定

| 条件 | 输出 |
|---|---|
| C < 0.60 | 中性，置信度=低；理由必须写“有效数据覆盖不足” |
| C ≥ 0.60 且 S ≥ +0.30 | 偏多 |
| C ≥ 0.60 且 S ≤ -0.30 | 偏空 |
| C ≥ 0.60 且 |S| < 0.30 | 中性 |

初始置信度：

- 高：C≥0.80，库存因子可用，且至少一个供需因子可用，并无“强因子反向冲突”；
- 中：C≥0.60 但不满足“高”；
- 低：C<0.60，或存在重大数据口径冲突。

“强因子反向冲突”定义为：某一权重≥0.25 的可用因子评分与最终方向相反，且其绝对值=2。重大数据口径冲突指同一核心数值在不同来源中因口径不一致而无法确定可用值，普通转载差异不在此列。

这些阈值是 v1 的待验证起点，不能在每日研判中临时调整。

### 5.3 持仓修正器（不进入 S）

使用前 20 会员多单、空单及各自增减，计算：

```text
净持仓 = 前20多单合计 − 前20空单合计
净持仓变化 = 当日净持仓 − 前日净持仓
```

必须同时记录合约范围；默认 99qh 全部合约口径不能与主力合约口径混称。

- 价涨+多增、价跌+空增：与价格方向一致，可提高一级置信度；
- 价涨+多减空加、价跌+空减多加：背离，下调一级置信度并写风险；
- 横盘+双增：只标记分歧扩大，不猜突破方向；
- 只有单日净持仓、没有增减或连续 3–5 日观察：不改变置信度；
- 移仓换月期：先标记移仓噪声，不做强解释。

持仓修正只调整置信度与风险，不把中性直接翻成多/空，也不覆盖止损纪律。

### 5.4 成本利润修正器（不进入 S）

成本利润输出三项：成本区间、生产利润、供给响应状态。

- 只有“行业亏损”：结论为“存在成本支撑逻辑，但反转未确认”，不得因此加分做多；
- 亏损 + 净冷修 + 日熔量持续下降：确认供给收缩，证据分别由供给因子评分；
- 高利润 + 复产/点火：提示供给恢复压力，由供给因子评分；
- 成本估算必须列出单耗、原料价格、燃料路线和来源；缺数据就只引用公开周度利润，不编造精确成本线。

成本只可作为 S2 外侧的产业逻辑参照，不能覆盖实际市场结构，也不能作为止损外移理由。

### 5.5 事件修正器

每个事件记录：事实、日期、来源、传导链、预期影响方向、有效期、反驳条件。

- 未核实标题不进入框架；
- 单次事件不直接修改 S；它通过供给、需求、库存、期现数据兑现后再评分；
- 重大未决事件可降低置信度或触发现有观望条件，但不得成为扛单理由。

## 六、与技术区间和执行层的接口

1. 方向层输出：`方向 / S / C / 置信度 / 主要支持因子 / 主要反向因子`。
2. 技术层继续独立计算 S1/S2/R1/R2 与 ATR5，禁止用方向分直接拉大或缩小区间。
3. 基本面方向与技术方向冲突时必须显式披露，不得只保留支持交易方向的证据；是否观望沿用研究员当前规格。
4. 触发、止损、目标仍由当前规格参数生成；框架 v1 不修改 ATR 参数，不承诺提高入场率或胜率。
5. 成本位、现货价和库存均不能作为触发价被触及后的止损放宽理由。
6. F2 接入时，日报需新增“因子评分表”，但正式修改 glass-researcher 规格必须另走变体协议；本框架部署本身不改变 v4 行为。

### 7.3 Skill 边界（F2）

- `skill-inventory`：库存趋势、同比与结构标签；
- `skill-supply`：日熔量趋势与冷修/复产净变化；
- `skill-demand`：订单与地产需求趋势；

各 Skill 只输出本契约字段；计算实现可迭代，输出字段变更视为框架接口变更。

## 八、结果评价与防 Gaming

### 8.1 现有指标不变

G1 日报产出、G2 胜率、G3 严格入场率、G4 零违规继续以 journal 和 performance.json 为准。框架 v1 部署后不得宣称这些指标已改善。

### 8.2 F3 计划新增指标

- **G5 方向准确率**：仅统计有完整基日/目标日行情且预测为偏多/偏空的样本；预测偏多且目标日收盘>基日收盘为正确，偏空镜像。另报 `direction_coverage = 非中性预测日数/有效预测日数`，防止全出中性美化准确率。
- **G6 区间覆盖率**：`max(0, min(实际最高,预判上沿)-max(实际最低,预判下沿)) / (实际最高-实际最低)`；同时报告“完整容纳率”（实际高低点均在预判区间内）。实际最高=实际最低时单独记 N-A。
- G5/G6 与交易胜率分开：方向正确但未触发不等于交易盈利，未触发也不计入胜率分母。

### 8.3 双轨样本

- 回测只用于验证计算、筛选假设和构造回归判例，单独建账；
- 前瞻样本才进入正式结果指标；
- 不得用回测胜率替换或稀释正式胜率。

### 8.4 复杂度与回滚

- 新因子必须证明独立增量价值，或替代一个旧因子；不得无限叠加高度相关指标。
- 同一证据通过供给与成本重复出现时，要披露相关性，不把它当成多份独立证据。
- 静态 PASS 只表示方法契约与数据映射通过审查；运行时准确率未改善时不得标为“结果性进化”。
- 框架变更后若前瞻 G5/G6 或交易指标持续恶化，按版本回滚；不能靠重写历史判分掩盖。

## 九、框架进化触发器

满足其一方可立项：

1. 每 10 笔有效前瞻样本或月度常规评审；
2. 同一 Skill 连续两轮优化仍不能收窄已确认差距；
3. 重复出现同类方向误判，且归因指向因子结构而非单次数据异常；
4. 数据源失效、口径改变或用户提出新方法需求。

每次变更必须附：差距证据、归因组件、变更假设、预期影响指标、回归判例、失败/回滚条件。无差距证据的“框架美化”不予立项。

## 十、v1 已知局限

1. 权重 30/25/25/20、阈值 0.30 和覆盖门槛 0.60 尚无样本验证；
2. 库存、供给、订单主要来自约周度转载，可能滞后 3–7 天；
3. 免费层没有稳定日度沙河 5mm 专项价，绝对基差频率受限；
4. 99qh 为第三方镜像，且默认全部合约口径，需防止与主力合约误配；
5. 多个公开渠道同源于少数产业样本，交叉一致不等于完全独立验证；
6. 成本、库存与供给存在经济上的相关性，加权评分并不代表统计独立；
7. v1 是方法契约，不是结果证明；真正的验收从 F2 实装、F3 指标上线和前瞻样本开始。
