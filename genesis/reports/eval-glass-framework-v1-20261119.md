### T3：独立算术输出与失败定位

使用独立 Node 实现：

```text
C = Σ可用权重
weighted = Σ(可用权重 × 分数)
S = C > 0 ? weighted / C : null
C < 0.60 => 中性/低置信；否则按 ±0.30 判方向
```

未引用草案自评。最终完整命令输出关键行：

```text
CASE_1_ACTUAL={"C":1,"weighted":0.45,"S":0.45,"direction":"BULLISH","confidence":"HIGH"}
CASE_1_EXPECTED={"C":1,"S":0.45,"direction":"BULLISH"}; C_MATCH=true; S_CHECK=true; DIRECTION_MATCH=true
CASE_2_ACTUAL={"C":0.45,"weighted":0.45,"S":1,"direction":"NEUTRAL","confidence":"LOW"}
CASE_2_EXPECTED={"C":0.45,"S":1,"direction":"NEUTRAL"}; C_MATCH=true; S_CHECK=true; DIRECTION_MATCH=true
CASE_3_ACTUAL={"C":0.55,"weighted":0.85,"S":1.5454545454545452,"direction":"NEUTRAL","confidence":"LOW"}
CASE_3_EXPECTED={"C":0.55,"S":null,"direction":"NEUTRAL"}; C_MATCH=true; S_CHECK=NOT_SPECIFIED; DIRECTION_MATCH=true
CASE_4_ACTUAL={"C":0.8,"weighted":1.1,"S":1.375,"direction":"BULLISH","confidence":"HIGH"}
CASE_4_EXPECTED={"C":0.75,"S":1.4666666666666666,"direction":"BULLISH"}; C_MATCH=false; S_CHECK=false; DIRECTION_MATCH=true

```

案例④的独立手算同构核对：

```text
C = 0.30 + 0.25 + 0.25 = 0.80
weighted = 0.30×2 + 0.25×1 + 0.25×1 = 1.10
S = 1.10 / 0.80 = 1.375
```

因此，**本轮给定案例④预期值与草案 L184-L188 的权重和公式不一致**。这不是可以通过引用草案自评或调整实现来消除的差异。裁决口径如下：

- 草案 C/S 公式在案例④的复算结果应为 0.80/1.375，不能如实写成 0.75/1.466666…。
- 本轮指定成功判据未通过，故 T3 按门槛记 FAIL；同时明确定位为**评估向量 oracle 错误**，不反向虚构“草案公式本身算错”。
- 缺失值未被当成 0 纳入分母：独立实现只累加非 null 因子；补 0 反例显示案例②会由中性变成 `C=1,S=0.45,偏多`，案例③会由中性变成 `C=1,S=0.85,偏多`，验证该防线的实际必要性。

### T4：通过项与核心失败项

**通过项：**

1. 成本不进入 S（L231），只有亏损不得加分做多（L235），供给响应仍由供给因子评分（L236-L238）。
2. 持仓只调整置信度与风险，不把中性直接翻成多/空（L212-L229）；事件不直接修改 S（L242-L248）。
3. 缺失/stale=null（L81、L107），缺失不进入分子分母（L191）。
4. 基差要求同区域、同品规、同税口径、元/吨（L158）；现货区间保留（L162）；全国元/㎡与 FG 元/吨禁止直接相减（L24）。
5. 强因子反向冲突有数值定义：权重≥0.25、方向相反、绝对分=2（L208）。独立注入 `{库存+2,供给+1,需求-2,基差null}` 得到 `C=0.8,S≈0.4375,偏多,strong_reverse_conflict=true,high_confidence_allowed=false`，断言 PASS。
6. 供给评分块 L129-L137 未出现“明显”，并有连续两周、13.5 万吨/日及产能大于/相等等可核比较；该项措辞检查本身通过。
7. G5/G6 独立公式冒烟通过：

```text
G5_MIXED={"validDays":4,"directionalDays":3,"correct":2,"accuracy":0.6666666666666666,"direction_coverage":0.75}
G5_ALL_NEUTRAL={"validDays":2,"directionalDays":0,"correct":0,"accuracy":null,"direction_coverage":0}
G6_FULL={"coverage":1,"fullyContained":true}
G6_PARTIAL={"coverage":0.5,"fullyContained":false}
G6_DISJOINT={"coverage":0,"fullyContained":false}
G6_FLAT={"coverage":"N-A","fullyContained":null}
G5_G6_INDEPENDENT_FORMULA_ASSERTIONS=PASS
```

全中性时 `accuracy=null` 且 `direction_coverage=0`，不存在借全中性获得虚假高准确率的路径。

**核心 FAIL：**

- 通用规则 L106-L107 规定：0 仅用于“已取得的证据确实中性或相互抵消”，缺失/stale 必须为 null。
- 供给评分表 L133 却规定：`日熔量稳定，或冷修与复产产能相等/无法判断净方向` 均给 0。
- “产能相等”可以是已取得的抵消证据，但“无法判断净方向”并不必然等于中性；若由冷修/复产数据缺失、口径冲突或覆盖不足造成，就应退出评分而非进入分子分母。特定评分表与通用 null 规则发生冲突，F2 可据此把未知当 0，触及本轮“缺失按中性处理即 FAIL”的红线。
- 修复需要改变供给因子的数据判定口径，不能由评估者代修，也不能降级为不影响计算的文案观察。
