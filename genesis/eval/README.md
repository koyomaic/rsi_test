# 评估集（held-out）

> **修改必须经用户批准**（genesis 对本目录的 edit 权限为 ask）。
> 评估集是整个自进化闭环的"地基"——它被污染，闭环就变成自嗨。

## 任务文件格式

每个任务一个文件，命名 `T<编号>-<名称>.md`：

```markdown
# T<编号>: <任务名>

- **被测对象**: genesis / genesis-architect / genesis-evaluator / <其他智能体id>
- **目标**: 这条任务检验什么
- **执行**: 给被测智能体的具体指令
- **成功判据（外部可验证）**: 必须能通过命令输出或产物文件检查判定
- **检查命令**: 具体的 shell 命令
- **难度**: easy / medium / hard
- **标签**: [smoke] [capability] [regression] ...
```

## 维护规则

1. 评估任务**不得**进入任何智能体的进化/学习数据（held-out 隔离）
2. 定期（建议每月）由用户轮换任务，防 benchmark 污染
3. 任务失效（外部依赖变化）时标注 `[deprecated]` 而非删除——保留回归历史
4. 新增任务优先覆盖：历史失败案例、真实任务流样本
